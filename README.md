# LinkVault

LinkVault is a full-stack web application for saving, organizing, and managing useful websites in one convenient location. It helps users avoid losing important resources inside cluttered browser bookmarks or scattered notes.

## Target Users

LinkVault is designed for college students, developers, researchers, and anyone who regularly saves online resources.

## Planned Features

- Add, edit, and delete saved links
- Organize links by category
- Search and filter saved links
- Detect duplicate and broken URLs
- Use AI to suggest categories and generate short descriptions

## Technology Stack

- **Frontend:** React
- **Backend:** Node.js and Express
- **Database:** SQLite
- **Containerization:** Docker Compose
- **Testing and CI/CD:** GitHub Actions
- **Deployment:** Google Cloud Platform
- **Version Control:** GitHub

## Project Timeline

- **Sprint 1:** Build the MVP with link creation, display, editing, deletion, categories, and search
- **Sprint 2:** Add AI assistance, duplicate and broken-link detection, testing, containerization, and cloud deployment

## Status

This project is currently in the planning and design stage.
